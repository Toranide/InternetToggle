# InternetToggle v1.0.0 — Draft Release Notes

InternetToggle is a lightweight Windows system-tray utility for quickly enabling or disabling one selected network adapter.

## What's included

- Choose a detected network adapter instead of relying on a hardcoded Ethernet interface.
- Toggle the selected adapter using the tray menu or the global shortcut Ctrl + Alt + T.
- Remember the selected adapter for the current Windows user.
- Optionally create or remove the Windows sign-in scheduled task.
- Show the selected adapter's reported state and display useful error notifications.
- Build a self-contained, single-file Windows x64 executable through GitHub Actions when runners are available.

## Important limitations

- InternetToggle enables or disables one adapter. It is not a firewall and cannot ensure that all internet access is blocked if other adapters, VPNs, or routes remain active.
- The displayed state reports whether Windows considers the adapter administratively enabled; it does not verify that the internet is reachable.
- The application requires administrator privileges for adapter changes.
